# Simple Interest Calculator

This project is a simple interest calculator built using HTML, CSS, and JavaScript.

## Features
- Calculates simple interest
- User inputs principal amount, rate of interest, and time
- Displays the calculated interest

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Enter the principal amount
2. Enter the rate of interest
3. Enter the time period
4. Click the calculate button to see the result
